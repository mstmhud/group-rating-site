# 🌸 群事件评分站

> 一个给群友互相"记账"的小站：谁做了什么事，发上来让全群打分，**分数越低越丢人**。
> 纯原生 HTML/JS，零依赖、零框架，双击就能玩，也能一键部署成全群共享的多人版。

## ✨ 它能干什么

- **📌 事件打分区**（核心玩法）：选一个"事件人"（可以是注册群友，也可以**手填没注册的人**），写清楚 TA 干的事，全群打 1–10 分；打分后 10 秒内可改，之后锁定 —— 想清楚了再打
- **💬 诋毁区**：纯吐槽，可以带图、点赞、评论，不能打分
- **🏆 排行榜**：总榜 & 人物榜，按**平均分从低到高**排 —— 越靠上越招人恨
- **🏷 标签区**：标签是"消耗品"，签到/评论/打分/发帖才能赚额度，给别人贴标签才扣，防止滥用
- **📊 统计区**：谁手松、谁毒舌（每人打分分布直方图），事件占比环形图
- **✉️ 站内信箱**：被评论/被打分/管理员通知，未读红点
- **🔧 管理员后台**：删帖、禁言（1小时～永久）、重置密码、群发通知、数据导入导出
- **🌸 二次元界面**：樱花天空背景、毛玻璃卡片、平滑过渡动画，支持 `prefers-reduced-motion`

## 🚀 两种玩法

### 玩法一：本地单人模式（零配置）

直接双击 `index.html`，用 Chrome / Edge 打开即可。

- 数据只存在**这台电脑的浏览器**里，不上网、不丢失（清缓存除外）
- 每个人在自己电脑上打开是**各自独立**的数据
- 建议：隔段时间到「数据与设置」导出备份 JSON

### 玩法二：多人共享版（部署到服务器）

`server-app/` 目录是多人版：Node 服务端 + 云数据库，全群共用一份数据，别人的打分 4 秒内自动出现在你的页面上。

- 零 npm 依赖，一个 `node server.js` 就能跑
- 密码 scrypt 服务端哈希、签名 Cookie 会话、注册邀请码、接口限流
- 详细步骤见 **[server-app/README-DEPLOY.md](server-app/README-DEPLOY.md)**（Render 免费套餐 + Supabase 免费数据库，$0 上线）

## 📁 目录结构

```
index.html            入口（本地模式双击这个）
css/app.css           樱花天空主题样式
js/store.js           数据层（本地模式；HTTP 访问自动切换多人模式）
js/store-server.js    多人模式桥接补丁
js/app.js             路由与页面外壳
js/pages/*.js         各板块页面（事件/诋毁区/排行榜/统计区/标签区…）
assets/bg.jpg         背景图
server-app/           多人版（Node 服务端 + 部署手册）
使用说明.md            本地版使用说明
```

## 🛠 技术栈

原生 JavaScript（ES5 语法，兼容性拉满）+ 原生 CSS + Node.js 内置模块。没有 webpack、没有框架、没有 npm 依赖 —— 拉下来就能跑。
